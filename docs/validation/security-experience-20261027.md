# 账户安全、设备与 API 密钥体验验收 · 2026-10-27

本轮从 10 月 26 日运行至 27 日，证据目录沿用开始日期。未修改后端与原生 Client 契约。

- 三页共用验证码字段与现有对话框、按钮、图标、颜色及动效规则。发送验证码和写入期间锁定表单及关闭操作，即时锁阻止同一点击批次重复请求。
- 密钥卡片支持完整公钥、权限、IP/CIDR 白名单、创建/使用时间与撤销状态。创建结果必须包含完整密钥记录和秘密值；秘密值默认遮挡，可显示、复制、手动选取并明确确认保存；关闭前询问，未确认保存不能继续创建。
- 创建、编辑白名单、撤销均核对具体目标，失败或不完整创建结果要求重新读取，不自动重新创建。关闭失败弹窗后仍保留核对提示。秘密值、密码、验证码不写入本地存储。
- 设备、登录 IP 与 MFA 独立读取，部分故障仍展示已知设备，未知验证要求不猜测为关闭。无 deviceId 的设备沿用真实 sessionId 退出接口，大整数不取整；设备封禁与 IP 封禁分别展示。仍沿用原有内网地址隐藏策略，最多读取最近 100 个设备与 100 条 IP 记录。
- 密码二次输入不匹配不发请求；安全场景保留强制提现验证。MFA、场景、密钥和设备响应校验身份、状态与必填字段，错误与真实空数据分开。
- 页面按用户 ID 隔离，取消旧读取和离页请求；同一用户刷新凭证不丢失一次性秘密值。直接打开 `/api` 的 Vite 代理仅匹配 `/api/` 后端路径；导航订阅建立后同步一次当前地址，覆盖子组件首次挂载时的登录重定向。
