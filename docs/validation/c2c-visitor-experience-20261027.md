# C2C 访客入口与登录返回验收

日期：2026-10-27。本记录仅覆盖本批改动，整体 UI 与功能完善任务尚未全部验收。

## 结果与范围

访客 `/c2c` 连接现有公开市场和广告接口，可筛选、分页，并通过登录继续交易。`/c2c/messages` 保留消息登录入口。普通登录、安全验证、邮箱验证及登录/注册互切保留原 C2C 目的地；返回参数仅接受 `/c2c`、`/c2c/messages`，没有目的地时仍进入资产页。登录不触发下单。

市场目录与已登录页面共用校验；公开广告校验市场、买卖方向、状态、分页及重复记录，金额维持原始十进制字符串。加载、错误、空结果和暂停开放分别展示。迟到筛选响应被取消；访客不读取订单、收款资料或商家私有状态。窄屏长精度报价调整字号，已检查测试价格的数字保持一行。

后端依据：`C2cController.markets/offers` 的公开签名、现有 `C2cStatusController` 和 `authApi` 登录/验证契约。没有修改后端或原生客户端契约。CodeGraph 工具本轮不可用，按已知文件核对源代码。

## 浏览器实际操作

Chromium 153.0.8010.12；1440×1000、390×844、320×844；实际点击主题按钮，检查深浅主题并滚动查看广告。6 组检查通过，无未预期页面或控制台错误。

1. 访客进入市场，错误广告响应显示可重试错误，不显示假空页；此阶段没有私有读取、认证头或写请求。
2. 点击买卖方向、前后页，输入非法/有效金额并快速切换筛选；迟到响应不覆盖新广告。错误市场方向和 503 都可恢复。
3. 分别查看真实空结果、业务关闭、运行关闭，以及长商家名、长精度价格在桌面和窄屏中的完整显示。
4. 点击登录、注册和返回登录；普通登录返回市场，带安全验证的登录返回消息；没有发送 C2C 交易写请求。
5. 必须邮箱验证时保留目的地，提交合成验证码后回到市场；清除合成会话恢复公开入口。
6. 公开页持续观察 60 秒，每 10 秒采样；没有后台私有读取或额外 C2C 轮询。
