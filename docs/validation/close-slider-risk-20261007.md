# 平仓比例与强平价显示验证（2026-10-07）

普通平仓表单原来未渲染比例滑块；现在与止盈止损共用按持仓计算的整张数量，支持手动数量反映实际百分比。双向持仓可选择多仓、空仓；切换合约、账户、保证金模式、仓位方向或委托类型会清空旧数量。没有对应仓位时禁用滑块和相应平仓按钮，提交继续使用现有只减仓和数量校验。

风险接口返回 `RiskPositionSnapshotResponse`，不包含普通持仓的 `realizedPnlUnits`。原 `loadPositionRisk` 使用 `PositionListSchema`，因此正确的强平价响应被校验拒绝。现使用独立 `PositionRiskListSchema`，保持普通持仓必须包含已实现盈亏的约束。合法的 `liquidationPriceTicks: null` 仍表示没有可返回的价格边界，不伪造数字。

验证：

- 构建通过；17 项相关测试通过，包括空强平边界、缺失/非法风险响应、精度及正负仓位百分比。
- 测试服务器真实账户、BTC 180 张多仓：50% 为 90 张，手动 45 张显示 25%，100% 为 180 张；无空仓时平空按钮不可用。
- 桌面 1440px、移动端 390px，通过本地开发代理连接真实 REST/WebSocket，强平价显示 28,191.3 USDT，与服务端返回的 281913 ticks 一致。没有提交实际平仓订单。
- 本次六个变更文件的 lint 通过；全项目 lint 仍被原有 `global.css` 的 38 条 `noDescendingSpecificity` 警告阻断。已验证该文件与 HEAD 哈希相同，本次未修改它。
- 其余产品线没有执行真实下单；共用选择器的方向、保证金模式和整张精度由单元测试覆盖。
