# 消息、公告与帮助体验验收 · 2026-10-26

本轮沿用现有接口，完善阅读、筛选和已读反馈；未修改后端或原生 Client 契约。

- 帮助中心搜索延迟 200ms 发起，切换搜索/分类时立即清除旧结果并取消请求。错误可重试，快捷文章会展开正文并定位键盘焦点；正文保留换行。
- 消息中心按登录用户隔离，区分加载、异常、真实空列表与零未读；消息缺字段、重复 ID 或无效时间不会当作成功响应。单条/全部已读有即时防重复、忙态与失败提示，失败保留正文。
- 公告中心访客可阅读，登录后才发送已读请求；语言、用户和产品范围变化重建页面。晚返回的已读结果不会替换当前详情。
- 公告每页 50 条，上一页/下一页限制同时驻留的条数；未读筛选明确作用于当前页。列表和详情各自可滚动，手机可返回列表。
- 弹窗复用原生对话框的焦点和 Escape 行为，可关闭而不标记已读；“阅读并关闭”失败会显示错误并允许重试。每个用户最多保留 200 个已展示版本标记，存储不可用仍能查看。
- 消息、公告 ID 与公告版本均保留精确十进制字符串；公告导航计数取消旧请求，并按用户/语言核对所属范围。

复现：

```sh
npm run lint -- --diagnostic-level=error
npm run typecheck
npm test
npm run build
npm run dev -- --host 127.0.0.1 --port 5183
QA_PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs QA_CHROMIUM=/path/to/chromium QA_OUTPUT=/path/to/evidence node scripts/content-experience-qa.mjs
```

浏览器实际操作搜索、清除、分类、展开正文、逐条/全部已读、分页、切换账户/语言、访客阅读、弹窗关闭/重试和反复切页，覆盖 1440×1000、390×844、320×844 与深浅主题。命令结果、截图与 60 秒观察见 [机器记录](content-experience-20261026.json)。

限制：全部 HTTP、会话与消息为显式隔离契约数据，未写入真实消息或发布真实公告；未进行真实多端已读同步、真实投放或全权限联调。消息接口只返回本视图最近 100 条，本轮未新增更早消息的历史接口。TaskDuration/ScriptDuration、DOM、监听器和堆观察仅描述本机短时运行，不代表生产性能结论。全站目标继续推进。
